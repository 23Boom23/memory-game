# Memory Game

Игра на поиск 8 пар среди 16 карточек. Карточки перемешиваются при загрузке и при запуске новой игры. Совпавшие пары остаются открытыми, несовпавшие закрываются через 1 секунду. Победы сохраняются в таблице десяти лучших результатов браузера.

## Запуск

Откройте `index.html` в браузере. Сборка, сервер и установка зависимостей не нужны.

## Что важно запомнить по заданию

- В исходном `body` находится только `script`; весь интерфейс создаёт JavaScript через `document.createElement`.
- Один ход засчитывается после открытия второй доступной карточки. Повторный клик и клик по найденной паре игнорируются.
- Во время показа несовпавшей пары поле заблокировано на 1 секунду. Новая игра отменяет старый таймер сразу.
- Оба окна используют общий код. Их закрытие не меняет состояние игры.
- Победа записывается в `localStorage` один раз. Таблица содержит до 10 результатов: меньше ходов выше, при равенстве выше более ранняя игра.
- Для сдачи нужен публичный репозиторий `memory-game`, ветка `memory-game`, открытый PR `Memory Game` в `main` и доступный без авторизации деплой. Ссылку на деплой разместите в описании PR, ссылку на PR отправьте в RS App.

Иллюстрации карточек созданы специально для этой игры и лежат в `assets/`.
